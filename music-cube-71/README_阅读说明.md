# 音乐魔方71首背景资料阅读说明

整理日期：2026年11月5日。这是目前已有资料的阶段汇编，仍有待核实的创作背景、版本关系与录音细节，不代表所有背景故事均已查明。

本资料按原始清单顺序收录71项作品：29项沿用既有曲库身份，42项按附件编号单列。附件编号用于查找资料，不代表新分配的正式曲库ID。原始清单内容保持不变。

## 阅读方式

- 《音乐魔方71项背景资料》为完整合辑，可以连续阅读。
- 《曲目索引》提供逐曲链接及相关独立来源数；另附JSON索引，便于检索或整理。
- “逐曲”文件夹包含71篇独立资料。
- 每篇分为“曲目档案”“创作与制作背景”“音乐魔方收录与版本”“资料来源”“核验边界与待补”五栏。

## 资料边界

当前71项中，27项有至少三个相关独立来源，44项仍不足三个。来源数量与故事完整度分开判断：发行目录、游戏公告和传播记录可以核实部分事实，但不等于作者已解释创作过程，也不等于游戏母带、剪辑或所有参数已核实。

原曲、翻唱、重混、不同平台录音及游戏采用版本按各自证据范围区分。同名作品不自动合并；不明确的关系和不同报道的分歧保留在正文中。公开引用链接保留，缺少材料之处不以猜测补齐。

此前明确的13项自制谱不纳入背景研究。身份尚未查清的条目不会因此被判定为自制谱。音乐魔方的29项既有身份也会出现在全版本汇编中，阅读两套资料时不应重复计数。
